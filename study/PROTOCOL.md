# Workflow observation v1

Two tasks, in fixed order: A uses the SixArm sections 6–7 excerpt with two ordinary PDFs; B uses the Common Paper NDA and the actual recorded Redline Referee workbench. Four minutes suggested per task, no time cutoff. Each task has two substantive edits and the same false formatting-only cover note. Source inputs and answers were frozen in data/external/LOCK.json before the API run. Task B becomes available only after its review completes without API errors.

Collect an anonymous random ID, phase, identified edits, signing decision, reason, confidence 1–5, browser wall time and server receipt time. Switching windows counts; model precomputation time is excluded and must be reported separately. Raw responses stay in git-ignored out/study/ and are not published. Automated walkthroughs must use ?preview=1 and must never count as human evidence.

Score manually against frozen gold:

- A1: initial term one calendar week → four calendar weeks.
- A2: first aggregate liability cap 100% → 200%. The per-project cap remains 100%; it is not a third edit.
- B1: prior written approval → prior notification for third-party disclosure.
- B2: cease using → continue using Confidential Information after termination.
- Neither returned copy is safe to sign solely on the formatting-only assurance. Identifying the substantive edits and requesting review/correction is a safe judgment.

Report hits/2, false findings, signing decision, elapsed time, confidence and comments for each phase. Ambiguous responses remain unscorable. Only two completed phases form a paired observation.

Limitations: one participant, unblinded, different agreements, fixed order, learning effects, no independent task-equivalence calibration and no independent adjudicator. Do not interpret a time or hit-rate difference as a causal productivity gain or population accuracy. No actual signature outcome is observed.
